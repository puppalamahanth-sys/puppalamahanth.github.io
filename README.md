# Mahanth's Website 🚀

**Live site:** [https://puppalamahanth-sys.github.io](https://puppalamahanth-sys.github.io)

Built by **Mahanth**, a first-year ECE student learning to become an AI engineer. Made with plain HTML, CSS, and JavaScript—no frameworks.

## Pages

| Page | What it does |
| :--- | :--- |
| `index.html` | Home page with intro and project cards |
| `about.html` | About me and what I'm learning |
| `game.html` | Guess the Number, with a saved best score |
| `rps.html` | Rock Paper Scissors with a scoreboard |
| `calc.html` | Keypad calculator with keyboard support |
| `todo.html` | To-do list saved in the browser |
| `highway.html` | Endless arcade highway racer with sound effects |
| `signals.html` | Signal Visualizer — Interactive sine, square, triangle, and noisy wave plotter |
| `style.css` | One shared stylesheet for every page |

## Features
* Responsive layout for phones and computers
* Automatic dark mode (`prefers-color-scheme`)
* Tasks and high scores saved with `localStorage`
* Input validation so the apps never break on bad input
